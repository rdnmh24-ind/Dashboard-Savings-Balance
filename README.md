# Savings Balance Growth Trend (Creating an Interactive Dashboard using MS Excel)

Monitor the final savings balances across all 41 branches. Enter the branch code in the "Insert" field to update the chart for the specific branch you wish to monitor.

## Dataset Used
<a href="https://github.com/rdnmh24-ind/Dashboard-Savings-Balance/blob/main/Dashboard%20Tabungan.xlsx">Dataset</a>

## Insight
- Analysis of the savings portfolio.
- MtD, YtD, and YoY growth.
- Ticket size per account.
- Number of new accounts opened.
- Strength of savings products by branch.
Dashboard Interaction <a href="https://github.com/rdnmh24-ind/Dashboard-Savings-Balance/blob/main/DASHBOARD%20TABUNGAN.png">View Dashboard</a>
Dashboard Interaction <a href="https://github.com/rdnmh24-ind/Dashboard-Savings-Balance/blob/main/DASHBOARD%20TABUNGAN%20II.png">View Dashboard</a>

## Process
Enter the branch code in the "Insert" field to break down the branch's savings balance.
Click the slicer to view balances for specific months.
Use the chart's filter feature for a deeper analysis.
